Values used when the spreadsheet has no matching column (or the cell is empty). A column with the same name always wins, so you can personalise any variable per row. Variables can contain HTML and other merge fields.

How merge fields work
  • {{First Name}} fills from the column “First Name” (case, spaces and underscores are ignored, so {{FIRST_NAME}} works too).
  • {{First Name|there}} uses “there” when the cell is empty.
  • {{Company:url}} URL-encodes the value (for links).
  • Built-ins: {{EMAIL}}, {{NAME}}, {{SENDER_NAME}}, {{SENDER_EMAIL}}.
  • Rows with a missing field and no fallback are flagged and skipped by default.

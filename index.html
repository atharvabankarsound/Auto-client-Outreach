Used for the “Plain personal email” style and as the text fallback inside designed emails. Emails sent this way don't get your Gmail signature, so add your sign-off here.

Default values for merge fields. A spreadsheet column with the same name always wins, so any variable can be personalised per row. Values can contain HTML and other merge fields.

How merge fields work
  • {{Show}} fills from the column “Show”. Case, spaces and underscores are ignored, so {{FIRST_NAMES}} matches “First Names”.
  • {{First Names|there}} uses “there” when the cell is empty. {{Show:url}} URL-encodes the value for links.
  • Built-ins: {{EMAIL}}, {{NAME}}, {{SENDER_NAME}}, {{SENDER_EMAIL}}.
  • A missing field with no fallback is flagged in the preview, and that email won't send until it's fixed.
